# 環境安裝與跑起 BookReview：踩雷提示

（組長 2026-10-10 實際跑過一遍整理，Mac 為主；Windows 同學用官方安裝檔即可）

## 要裝什麼
- Java 17 以上（老師說明：JDK 17 或更新）。已經有新版（例如 26）不用另外裝，實測可跑。
  沒有的人建議用 https://adoptium.net 的 Temurin 17 安裝檔，比 brew 穩。
- MongoDB Community
- VS Code ＋ Extension Pack for Java

## Mac 安裝 MongoDB（一行一行貼）
    brew tap mongodb/brew
    brew trust mongodb/brew
    brew install mongodb-community
    brew services start mongodb-community
    brew services list | grep mongo     ← 看到 started 就成功

## 常見問題
1. 第一次用 brew 很慢（會先自動更新），可能 10–20 分鐘，不要關終端機視窗。
2. 出現 "Refusing to load formula ... from untrusted tap"：先跑 `brew trust mongodb/brew`（MongoDB 官方來源）。
3. 下載到一半斷掉 `curl: (92)` 或 `curl: (18)`：
   `echo 'http1.1' >> ~/.curlrc` 和 `export HOMEBREW_CURLRC=$HOME/.curlrc`，再重跑 brew install。
   Java 一直斷就改用瀏覽器下載 Adoptium 安裝檔。
4. 畫面停在 `[y/n]` 時輸入 y 按 Enter。

## 跑起 BookReview
    cd 到 範例/BookReview/BookReview   ← 注意是兩層 BookReview
    chmod +x mvnw
    ./mvnw spring-boot:run
看到 `Started BookReviewApplication` 後開 http://localhost:8080 ，新增一筆書評試試。
- 伺服器跑著時終端機會停住，不要關；要停按 Ctrl + C。
- 驗證資料：瀏覽器開 http://localhost:8080/api/reviews ，或 `mongosh test --eval 'db.bookReviews.find()'`

## VS Code
- 專案資料夾裡打 `code .` 開啟；提示安裝 Extension Pack for Java 按 Install。
- 跳出「升級到最新 LTS（Copilot modernization）」按 Not Now，不要升級；Null analysis 按 Disable。
- VS Code 預設不自動存檔，分頁有白點就是沒存，Cmd + S。
- Cmd + F 搜尋；按住 Cmd 點方法名稱可跳到定義。
